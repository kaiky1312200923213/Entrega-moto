# Entrega de Moto — Jogo de Entregas

**Autor:** Kaiky Yoshio Ono Marins  
**Categoria:** JavaScript · Canvas · Jogos para navegador  
**Status:** Protótipo

## Visão geral

Pequeno jogo de entregas desenvolvido com HTML, CSS e JavaScript. A lógica desenha o cenário em um canvas e acompanha indicadores de dinheiro, combustível e quantidade de entregas realizadas.

**Demonstração:** [moto-entrega.netlify.app](https://moto-entrega.netlify.app/)

## Mecânicas presentes no código

- Personagem controlado pelo teclado.
- Geração de destinos de entrega.
- Atualização de combustível e dinheiro.
- Contagem de entregas concluídas.
- Ciclo de atualização e renderização do jogo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API

## Como executar

Abra `index.html` em um navegador moderno. Os arquivos principais são `game.js`, `index.html` e `style.css`.
